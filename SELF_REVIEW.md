# Self Review - Library Management System

## What I Built
I implemented a simple Library Management System using Python that manages library members, books, and book transactions.

---

## Features Implemented

### 1. Library Member Management
- Created a Member class to store user details.

### 2. Book Management
- Created a Book class to manage book details and availability.

### 3. Transaction System
- Implemented issue and return functionality.
- Automatically updates book availability.

---

## Challenges Faced
- Initially faced issues with environment setup and imports.
- Resolved by restructuring project and using clean folder setup.

---

## What I Learned
- Object-Oriented Programming in Python
- Relationship between entities (Member, Book, Transaction)
- Basic system design thinking
- Debugging import and file structure issues
